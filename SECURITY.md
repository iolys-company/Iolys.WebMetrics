# Security policy

## Supported versions

Until version 1.0, security fixes are provided for the latest published preview only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature in the **Security** tab of this repository. Do not disclose a suspected vulnerability in a public issue or discussion.

Include the affected version, deployment model, reproduction steps, potential impact, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as reasonably possible and coordinate disclosure after a fix is available.

Do not include production analytics databases, visitor keys, IP addresses, or other personal or confidential data in a report.
